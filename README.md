# updatex

Терминальный помощник для обновления Fedora. Создано **sxxlxxr при участии GPT-6 Sol**.

⚠ **Экспериментальный проект.** На практике проверены просмотр обновлений, проверка NVIDIA/Vulkan и обновление Flatpak. Полный цикл обновления RPM, нового ядра и последующей проверки NVIDIA пока не испытан. Скрипт вызывает `sudo` для системных RPM-пакетов; перед запуском ознакомьтесь с его кодом.

## Возможности

- Краткая сводка обновлений и подробный список по запросу.
- Режимы «Обновить всё», «Только систему», «Только программы» и «Только Flatpak».
- Предупреждение, если обновление графических компонентов может вызвать повторную сборку шейдеров в играх. Это возможность, а не гарантированное последствие.
- Проверка NVIDIA и Vulkan. После обновления ядра или NVIDIA — проверка готовности модуля NVIDIA для установленного ядра. Окончательный результат можно проверить только после перезагрузки.
- После загрузки самого нового ядра, при наличии хотя бы трёх установленных ядер и исправных драйверов, предложение удалить самое старое. Удаление только с подтверждением DNF.

**Важно:** DNF не делит все RPM-пакеты однозначно на «систему» и «программы». `updatex` распознаёт часть приложений по ярлыкам рабочего стола. В режиме «Только систему» могут обновляться нераспознанные программы; режим «Только программы» может затронуть системные зависимости. Всегда проверяйте список транзакции, который DNF показывает до установки.

Автоматическая проверка при входе после перезагрузки **не настроена**. Запустите `updatex` и выберите «Проверить драйверы и старые ядра» самостоятельно.

## Требования и проверка

Поддерживается **Fedora с DNF5**. Не предназначен для Ubuntu, Arch и других дистрибутивов. Для работы необходимы `bash`, `dnf`, `rpm` и `sudo` — обычно они уже установлены в Fedora.

Проверить команды:

```bash
for cmd in bash dnf rpm sudo flatpak fzf vulkaninfo; do
  command -v "$cmd" || echo "Не найдено: $cmd"
done
```

Дополнительные пакеты:

```bash
sudo dnf install flatpak fzf vulkan-tools
```

- `flatpak` нужен для обновлений Flatpak.
- `fzf` даёт меню со стрелками и рисунком; без него доступно меню с цифрами.
- `vulkan-tools` предоставляет `vulkaninfo` для необязательной проверки Vulkan.

**Если уже используется NVIDIA**, проверить инструменты можно так:

```bash
for cmd in nvidia-smi akmods modinfo; do
  command -v "$cmd" || echo "Не найдено: $cmd"
done
```

`modinfo` входит в пакет `kmod`, `akmods` — в `akmods`, `nvidia-smi` на Fedora с RPM Fusion предоставляется пакетом `xorg-x11-drv-nvidia-cuda`. Не устанавливайте драйвер NVIDIA по этому списку вслепую: способ установки зависит от видеокарты и настроенных репозиториев. На компьютерах без NVIDIA эта проверка пропускается.

## Установка

Скачайте файл, просмотрите его и установите в пользовательский каталог:

```bash
curl -fL -o updatex https://raw.githubusercontent.com/sxxlxxr/updatex/main/updatex
less updatex
install -Dm755 updatex ~/.local/bin/updatex
~/.local/bin/updatex
```

Если `~/.local/bin` есть в `PATH`, в дальнейшем достаточно команды `updatex`.

## Обновление самого updatex

Пока обновление **ручное**: повторите скачивание и установку из раздела выше. GitHub-версия не обновляется командой `dnf upgrade`. Перед заменой скрипта просматривайте изменения: после установки он сможет выполнять системные действия с `sudo`.
